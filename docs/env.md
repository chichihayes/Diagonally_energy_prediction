# docs/env.md — Diagonally Energy Prediction

## Required environment variables

Copy `.env.example` to `.env` and fill in all values before running the API or training.

```
# Model path
MODEL_PATH_FORECAST=src/model/trained/model_forecast.joblib

# Claude API (for forecast chat)
ANTHROPIC_API_KEY=

# API server
API_HOST=0.0.0.0
API_PORT=8000

# Supabase
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key

# Electricity tariff (UK)
ELECTRICITY_TARIFF_GBP_PER_KWH=0.34
```

---

## Variable reference

| Variable | Required | Description |
|---|---|---|
| `MODEL_PATH_FORECAST` | Yes | Path to `model_forecast.joblib` — generated by `scripts/run_training_forecast.py` |
| `ANTHROPIC_API_KEY` | Yes | API key for Claude (used by `POST /api/v1/forecast/chat`). Get from console.anthropic.com |
| `API_HOST` | Yes | Host to bind Uvicorn (use `0.0.0.0` to accept all interfaces) |
| `API_PORT` | Yes | Port to run the API on (default `8000`) |
| `SUPABASE_URL` | Yes | Supabase project URL from the project dashboard |
| `SUPABASE_ANON_KEY` | Yes | Supabase anon/public key — used for client reads and inserts from the API |
| `SUPABASE_SERVICE_ROLE_KEY` | Yes | Supabase service role key — used for privileged writes that bypass RLS |
| `ELECTRICITY_TARIFF_GBP_PER_KWH` | Yes | UK electricity tariff in GBP per kWh — current rate ~£0.34/kWh (check Ofgem) |

---

## Notes

- Never commit `.env` — it is gitignored.
- `MODEL_PATH_FORECAST` must exist before starting the API. Run `scripts/run_training_forecast.py` to generate it.
- `ELECTRICITY_TARIFF_GBP_PER_KWH` is applied as `cost = predicted_kwh × rate`. Update when Ofgem revises the price cap.
- `SUPABASE_SERVICE_ROLE_KEY` bypasses row-level security — never expose it to the frontend.
