# docs/env.md — Diagonally Energy Prediction

## Required environment variables

Copy `.env.example` to `.env` and fill in all values before running the API or training.

```
# Model paths
MODEL_FULL_PATH=src/model/trained/model_full.joblib
MODEL_SIMPLE_PATH=src/model/trained/model_simple.joblib
MODEL_PATH_FORECAST=src/model/trained/model_forecast.joblib

# API server
API_HOST=0.0.0.0
API_PORT=8000

# OpenWeatherMap
OPENWEATHERMAP_API_KEY=your_openweathermap_api_key

# Supabase
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_ANON_KEY=your_supabase_anon_key
SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key

# Electricity tariff
ELECTRICITY_TARIFF_NGN_PER_KWH=68.00
```

---

## Variable reference

| Variable | Required | Description |
|---|---|---|
| `MODEL_FULL_PATH` | Yes | Path to `model_full.joblib` — generated by `scripts/run_training_full.py` |
| `MODEL_SIMPLE_PATH` | Yes | Path to `model_simple.joblib` — generated by `scripts/run_training_simple.py` |
| `MODEL_PATH_FORECAST` | Yes | Path to `model_forecast.joblib` — generated by `scripts/run_training_forecast.py` |
| `API_HOST` | Yes | Host to bind Uvicorn (use `0.0.0.0` to accept all interfaces) |
| `API_PORT` | Yes | Port to run the API on (default 8000) |
| `OPENWEATHERMAP_API_KEY` | Yes | OpenWeatherMap API key — free tier at openweathermap.org |
| `SUPABASE_URL` | Yes | Supabase project URL from the project dashboard |
| `SUPABASE_ANON_KEY` | Yes | Supabase anon/public key — used for client reads and inserts from the API |
| `SUPABASE_SERVICE_ROLE_KEY` | Yes | Supabase service role key — used for privileged writes that bypass RLS |
| `ELECTRICITY_TARIFF_NGN_PER_KWH` | Yes | NERC electricity tariff in Nigerian Naira per kWh — check current rate at nerc.gov.ng |

---

## Notes

- Never commit `.env` — it is gitignored.
- The three model path variables do not exist until the corresponding training script has been run.
- `ELECTRICITY_TARIFF_NGN_PER_KWH` is applied as a simple multiplier: `cost = predicted_kwh × rate`. Update the value when NERC revises the tariff without touching code.
- The OWM free tier allows 1,000 calls/day. The 10-minute cache in `weather.py` keeps usage well within that limit for a single-home demo.
- `SUPABASE_ANON_KEY` is safe to use from the API. `SUPABASE_SERVICE_ROLE_KEY` bypasses row-level security — never expose it to the frontend.
